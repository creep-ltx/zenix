TOUCH(1)			Zenix manual

NAME
    touch - create files or update their time

SYNOPSIS
    touch [-c] file...

DESCRIPTION
    Sets the modification time of each file to the current time. A file
    that does not exist is created empty, unless -c is given.

OPTIONS
    -c    do not create files that do not exist

EXIT STATUS
    0, 1 if a file could not be created or its time could not be set
    (a read-only filesystem: "read-only file system").

NOTES
    An access the user is not allowed is reported as "permission denied".
    Setting the time to now is allowed to the owner, root and anyone who
    may write the file; a given time (tar x, cp -p, mv) only to the owner
    and root.

SEE ALSO
    date(1), ls(1)
