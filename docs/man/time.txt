TIME(1)		Zenix manual

NAME
    time - time a command

SYNOPSIS
    time command [argument...]

DESCRIPTION
    Runs the command and then prints the elapsed time to standard error as
    real MmS.mmms.

NOTES
    The command runs in time's own process group, the shell's job: Ctrl+C
    reaches both (no time is printed then).
    Only wall-clock time: the kernel does not count CPU time per process
    yet. The command is looked up in /bin unless it has a slash.

EXIT STATUS
    The command's own status; 127 if it cannot be run.

SEE ALSO
