PS(1)			Zenix manual

NAME
    ps - list the running processes

SYNOPSIS
    ps

DESCRIPTION
    Prints one line for every process: its id, its parent's id, its
    priority, its niceness, its state, the memory it owns and the shared
    code it runs in kilobytes, and its program name. There are no options
    and no filtering.

    PID   process id
    PPID  parent process id (0 for the programs started by the kernel)
    PRI   the level it runs at now: 0 is the highest, 31 the lowest (nice
          0 is 16, the built-in servers' -10 is 8). A server serving a
          client shows that client's level if it is better than its own
          (priority inheritance); the idle process shows -
    NI    its niceness, -20 (most favoured) .. 19 (nice(1), renice(1))
    STATE ready    can run, waiting for its turn
          sleep    waiting for a timer (sleep)
          wait     waiting for a child to end (wait)
          io       waiting for input, output or a pipe
          msg      waiting for a server's answer, or (a server) for a request
          zombie   ended, not yet collected by its parent
          stopped  stopped by Ctrl-Z or a job-control request (fg, bg go on)
    MEM(K) the memory the process owns (its program's data and BSS - for a
          program without shared code its code too - and its stack)
    SHR(K) the shared code it runs: one copy for every process running
          the same program, not counted in MEM (0: none)
    NAME  the file name of the program (first 15 characters)

EXAMPLE (the numbers will differ)
      PID  PPID PRI  NI STATE    MEM(K) SHR(K) NAME
        0     0   -   0 ready         0      0 idle
        1     0  16   0 wait         25      0 boot
        2     0   8 -10 msg          35      0 diskd
        3     0   8 -10 msg          63      0 fsd
        ...

NOTES
    Zenix has room for 32 processes in all (a login and a shell on each of
    the ten consoles, the servers and the commands they run), so ps shows
    at most 32 lines.
    The idle process (pid 0) is listed first, with no level. boot is
    pid 1, diskd pid 2 and the root's server pid 3 on a normal boot; the
    servers (diskd, fsd or zfsd for the root and for each mount, and the
    services of /etc/svctab) have PPID 0, appear only once something
    first called them, and get a new pid when they are started again
    after a crash or a kill (dmesg says so).

SEE ALSO
