CONPREFS(1)			Zenix manual

NAME
    conprefs - the screen's settings

DESCRIPTION
    Another name for screenprefs(1) (a link to it). As conprefs it opens
    the form on the console; -q prints conprefs' old line
    ("conprefs: colours N|auto, font NAME, mode hires|hires-lace"). See
    screenprefs(1).

SEE ALSO
    screenprefs(1)
