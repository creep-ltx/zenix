TREE(1)		Zenix manual

NAME
    tree - show a directory tree

SYNOPSIS
    tree [-a] [-d] [directory...]

DESCRIPTION
    Lists the directory (default .) and everything below it, indented with
    |-- and `-- lines, and a count at the end. -a includes names that start
    with a dot; -d shows directories only.

NOTES
    Drawn with plain ASCII characters.
    Directories with any number of entries are walked, as deep as paths go. A
    path longer than 255 bytes (what a system call takes) is reported
    ("file name too long") and skipped, never cut short. A link target longer
    than 158 bytes is shown cut, ending in "...".

EXIT STATUS
    0, 1 if a directory or path below could not be read, 2 for a wrong
    option.

SEE ALSO
    ls(1), find(1)
