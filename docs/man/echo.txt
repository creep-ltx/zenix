ECHO(1)			Zenix manual

NAME
    echo - print its arguments

SYNOPSIS
    echo [argument...]

DESCRIPTION
    Writes the arguments to the standard output separated by single spaces,
    followed by a newline.

    This program has no options: "-n" is printed like any other word. The
    shell has its own built-in echo that does understand -n (no newline) and
    -e (backslash escapes); inside sh, "echo -ne 'a\n'" uses that one. See
    sh(1).

EXAMPLES
    echo hello world
    echo $HOME > where

EXIT STATUS
    0, or 1 when a write fails (a full disk): "echo: write error" and the
    reason are printed on the standard error. Into a closed pipe it ends
    by SIGPIPE (status 141), as any writer does.

SEE ALSO
    sh(1), printenv(1)
