LESS(1)			Zenix manual

NAME
    less, more - show text a page at a time

SYNOPSIS
    less file...
    command | less

KEYS
    Space, f         next page            b          previous page
    Enter, j, Down   next line            k, Up      previous line
    d, u             half a page          g, Home    top
    G, End           bottom
    /pattern         search forward       ?pattern   search backward
    n, N             next / previous match (a regular expression)
    h                help                 q          quit

    A short text is just printed. When the output is not a terminal, less
    acts like cat.

    Colour codes (SGR: ESC [ ... m, as ls --color and grep --color write
    them) pass through to the terminal, as GNU less -R does, and take no
    room on the line; each row ends with the colours reset, and a row that
    continues a long line starts with the line's colours. Other control
    characters are shown as ^X (ESC as ^[).

NOTES
    An access the user is not allowed is reported as "permission denied".
    Running out of memory is reported ("out of memory") and ends the command
    with a non-zero status; nothing is cut short silently.
    It pages as many rows as the terminal has (32 on PAL, 25 on NTSC). In
    a pipe (ls | less) the keys come from the console less runs on, its
    controlling tty, not from console 1.
