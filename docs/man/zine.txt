ZINE(1)				Zenix manual

NAME
    zine - run an AmigaOS program under Zenix

SYNOPSIS
    zine [--blob FILE] PROGRAM [ARGS...]

DESCRIPTION
    Runs PROGRAM, an AmigaOS executable, under ZINE: Zenix pauses, gives
    the program the machine and a small AmigaOS of its own
    (/lib/zine/zine.blob, loaded only when zine runs), and carries on at
    the prompt when the program ends. The disks are written out first;
    every Zenix program is paused where it stood while the Amiga program
    runs.

    Root and the members of the group zine may run it (root adds one
    with gpasswd -a NAME zine; it counts from their next login or su),
    and only at the Amiga's own console (not over ssh or telnet). zine is
    set-user-id root; it reads the program and its folder only where the
    user who ran it may, with that user's groups. A
    member of zine can do anything to the machine while a program
    runs, as root can. It needs fast RAM.

    ZINE is being built (DESIGN D29): the pause and the way back are
    tested; running real programs comes next.

    Ctrl-Amiga-Amiga while the program runs restarts the machine into
    Zenix.

OPTIONS
    --blob FILE   use FILE instead of /lib/zine/zine.blob (the tests'
                  /tests/zine/null.blob pauses and resumes only)

EXAMPLES
    zine /home/demos/mydemo

EXIT STATUS
    The program's return code; 1 when it could not run, crashed or was
    stopped; 2 for bad arguments.
