TELNET(1)		Zenix manual

NAME
    telnet - a terminal to another computer over the network

SYNOPSIS
    telnet [-a|-p|-x] [-i] [-r] [-e CHAR|none] HOST [PORT]

DESCRIPTION
    telnet connects to HOST (a name or an address) on PORT (23 when not
    given) and makes the console a terminal there: every key goes to the
    other computer (Ctrl-C included), and what it sends is shown. The
    window size (80x32 on PAL, 80x25 on NTSC) and the terminal type are
    told to the other side.

    Three modes:
    -a  an Amiga board (the default): Latin-1 in the console's own Topaz,
        terminal type ANSI. The Amiga console's codes are understood:
        the byte 0x9B as ESC [, the cursor off and on (CSI 0 SP p), the
        window bounds request (CSI 0 SP q, answered with the window
        size); CSI n u (the Amiga's line length) is dropped.
    -p  a PC board: the PC character set (CP437: box lines, blocks, the
        smiley set) through the PC font, loaded for this console from
        /usr/share/consolefonts/cp437-8x8.psf, terminal type ANSI. A line
        feed moves down only, the bytes 1-31 are drawn as glyphs.
    -x  a Unix host: xterm-like, terminal type XTERM-16COLOR; UTF-8 from
        the other side is shown in Latin-1 (other characters as ?), and a
        line feed moves down only, as xterm does.

    In both board modes the console wraps at the last column at once,
    ESC[2J also homes the cursor, bold (SGR 1) is the bright colour, the
    colours are the PC's (CGA) palette; ANSI music is swallowed, a form
    feed clears the screen, DOS's end-of-file byte is dropped. A board may
    switch on iCE colours (blink as bright backgrounds) with CSI ? 33 h,
    and switch between the PC and Amiga modes with SyncTERM's font code.
    With fewer than 16 colours telnet says once at the start that
    `colours 16` in /etc/console shows ANSI art fully, and how much more
    chip RAM that takes.

    Keys: Backspace sends BS in the board modes (DEL in the Unix mode),
    Del sends DEL; Swedish letters go as CP437 to a PC board (a letter
    CP437 lacks rings the bell and is not sent), as Latin-1 to an Amiga
    board, as UTF-8 to a Unix host.

    Ctrl-] opens a prompt on the bottom row: q closes the connection, z
    suspends telnet (fg brings it back), a, p and x switch to the Amiga,
    PC or Unix mode (the screen is cleared), Ctrl-] sends Ctrl-] itself,
    Return goes back.

OPTIONS
    -a          the Amiga board mode (the default)
    -p          the PC board mode
    -x          the Unix mode
    -i          iCE colours from the start
    -r          a plain TCP connection: no telnet protocol at all (as nc)
    -e CHAR     another escape key: a character, or ^X for a control key;
                none turns it off

EXIT STATUS
    0 when the connection ended (closed by the other side, or q), 1 when
    it could not be made (no such host, refused, the network down), 2 for
    a usage error.

NOTES
    No downloads yet (Zmodem is DESIGN D20's next step), no telnet server,
    no phone book. The console's font and rules are telnet's while it
    runs: they are put back when it ends or is suspended (the screen is
    cleared before the PC font goes, as its bytes would be junk in Topaz).
    Only Topaz from the ROM is used for Amiga boards (no other Amiga
    fonts are shipped). PC art was drawn for 8x16 cells: in the console's
    8x8 cells it looks as in the PC's 50-line mode. At 8 colours a bright
    colour is shown as the colour in bold and bright backgrounds as the
    plain colour.
    telnet runs one priority level below where it was started (nice 1),
    and writes the screen 256 bytes at a time, so the network keeps up
    over SLIP while a big screen is drawn.
    When the standard output is not the console (telnet host > file), the
    console's rules and the PC font are not set (each said once) and the
    call goes on; in the PC mode CP437 is then written as the nearest
    Latin-1 characters (box lines as - | +, blocks as #). When the keys
    come from a pipe or a file, telnet keeps the call until the other
    side closes it. A computer that disappears without closing the
    connection leaves telnet waiting: Ctrl-] q.
    Unencrypted: for the home network and for boards.
