TERM(1)			Zenix manual

NAME
    term - the terminal window of Zenix Desktop

SYNOPSIS
    term [-r ROWS] [-c COLUMNS] [-p X,Y] [-e COMMAND [ARGUMENTS]]

DESCRIPTION
    A window on the desktop (zdesk(1)) with the user's shell ($SHELL, else
    /bin/sh), or COMMAND, on a pseudo-terminal. It is the console's own
    terminal: the same escape codes, colours, UTF-8 and scrollback (200
    lines; Shift+Up and Shift+Down move through it), built from the same
    source; its 16 colours are the screen's nearest. TERM is
    xterm-16color.

    The window is 80 columns wide and ROWS rows high at first (24; 4 to
    the most the screen holds: 29 on PAL's 256 lines, 22 on NTSC's 200,
    32 interlaced); a resize gives it 20 to 80 columns and 4 to that many
    rows, in whole
    cells, and the program gets SIGWINCH (lines wrap at the new width;
    what lay beyond it comes back when the window widens). Output is
    shown as xterm's jump scroll does: what the program writes goes into
    the cells at once, but the window shows it at most every 30 ms while
    the output streams (one copy for all the lines it scrolled, then only
    the cells that changed) and at once when it pauses, so a long listing
    costs a few redraws a second, never one a line. Its menu (in the
    bar): Window, New terminal and Close. Closing the window
    hangs the pty up (SIGHUP to the program); the window goes when the
    program ends.

OPTIONS
    -r ROWS     the rows at first (4 to 29, 22 NTSC, 32 interlaced; 24)
    -c COLUMNS  the columns at first (20 to 80; 80): a window that fits
                beside the desktop's icons (the demo floppy's welcome)
    -p X,Y      where the window's frame goes, in pixels (else zdesk's
                choice); zdesk keeps it inside the screen
    -e COMMAND  run COMMAND instead of a shell (the rest of the line are
                its arguments)

NOTES
    At most 80 columns: the console's cell model keeps rows of 80. A wide
    character draws in one cell. No mouse selection and no clipboard yet;
    the bell is silent. The program starts once the window is shown, with
    the size it really got (80 columns and a frame do not fit the 640-pixel
    screen: zdesk makes it 78 or 79); a later resize is told by SIGWINCH,
    which the full-screen programs here (Ahiru, Sumi, ctop) do not follow
    yet.
