SYNC(1)			Zenix manual

NAME
    sync - flush data to disk

SYNOPSIS
    sync

DESCRIPTION
    Asks the filesystem server to write everything to disk. Today every
    write goes straight to the disk (write-through), so there is nothing
    waiting and sync returns at once; it is kept for scripts and for when
    delayed writes arrive (see ZenixFS in docs/zenixfs.md).

SEE ALSO
    df(1)
