RMDIR(1)			Zenix manual

NAME
    rmdir - remove empty directories

SYNOPSIS
    rmdir directory...

DESCRIPTION
    Removes each named directory, which must be empty. There are no options.
    To remove a directory with its contents use "rm -r".

EXIT STATUS
    0, 1 if a directory is not empty or cannot be removed, 2 usage error.
    Errors read "rmdir: DIR: REASON" with the system's reason ("directory
    not empty").

NOTES
    An access the user is not allowed is reported as "permission denied".
    A directory with entries says "not empty"; any other failure gives its
    reason. On ext2 an empty directory whose link count says it still has a
    subdirectory (one a power cut left without a name) also says "not
    empty": removing it would leave that subdirectory's ".." pointing at
    nothing. fsck.ext2 or e2fsck repairs the count.

SEE ALSO
    mkdir(1), rm(1)
