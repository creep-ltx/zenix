HOSTNAME(1)			Zenix manual

NAME
    hostname - print the computer's name

SYNOPSIS
    hostname

DESCRIPTION
    Prints $HOSTNAME (login sets it from /etc/hostname), else the first line
    of /etc/hostname, else "zenix". The name cannot be changed with this
    command: edit /etc/hostname (zinstall writes it), then log in again.

FILES
    /etc/hostname   the machine's name: 1-63 of a-z 0-9 -, one line

SEE ALSO
    uname(1)
