READLINK(1)			Zenix manual

NAME
    readlink - print where a symbolic link points

SYNOPSIS
    readlink link...

DESCRIPTION
    Prints the target path stored in each symbolic link. Says nothing and
    returns 1 for names that are not symbolic links. There are no options.

EXAMPLE
    readlink /bin/more         prints less

SEE ALSO
    ln(1), ls(1)
