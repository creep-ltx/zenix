EXPR(1)			Zenix manual

NAME
    expr - evaluate an expression

SYNOPSIS
    expr argument...

DESCRIPTION
    Evaluates the arguments as one expression and prints the result. Every
    operator and operand is a separate argument, so there must be spaces
    around them, and characters the shell treats specially must be quoted.
    Operators, from tightest to loosest binding:

        STRING : REGEX         match a basic regular expression (as sed's)
                               at the start of STRING: the text of the
                               first \( \) group, or else the number of
                               characters matched (0: no match)
        length STRING          the number of characters
        *  /  %                multiply, divide, remainder (whole numbers)
        +  -                   add, subtract
        =  !=  <  >  <=  >=    compare; numbers numerically, otherwise as
                               text; the result is 1 or 0
        &                      1st value if both are non-zero/non-empty,
                               otherwise 0
        |                      1st value if it is non-zero/non-empty,
                               otherwise the 2nd
        ( )                    grouping

EXAMPLES
    expr 2 + 3 '*' 4            prints 14
    expr length hello           prints 5
    expr file.txt : '.*\.\(.*\)'  prints txt
    expr abc : 'a.'             prints 2
    n=$(expr $n + 1)

    The shell can also calculate by itself: echo $((2 + 3 * 4)).

EXIT STATUS
    0 if the result is neither empty nor 0, 1 if it is, 2 on an error
    (division by zero, non-numeric operand, bad regular expression).
