EDIT(1)			Zenix manual

NAME
    edit - a text editor for the terminal

SYNOPSIS
    edit [+LINE] [file]

KEYS
    Ctrl+S   save                  F2         save as
    Ctrl+Q   quit (asks about unsaved changes)      F1   help
    Ctrl+Z   undo                  Ctrl+Y     redo
    Ctrl+C   copy                  Ctrl+X     cut          Ctrl+V   paste
             (with nothing selected: the whole line)
    Ctrl+K   cut the line          Ctrl+D     duplicate the line
    Ctrl+A   select everything     Shift + arrows   select
    Ctrl+F   find (a regular expression; a capital letter in the pattern
             makes the search case sensitive)
    F3, Ctrl+G   next match        Shift+F3   previous match
    Ctrl+R   replace; asks for each match: y yes, n no, a all, q quit
    Ctrl+L   go to line (LINE or LINE:COLUMN)
    F4       line numbers on / off
    Ctrl+Left, Ctrl+Right   start / end of the line
    Ctrl+Up, Ctrl+Down      start / end of the file
    Alt+Left, Alt+Right     a word back / on
    Alt+Up, Alt+Down        a page up / down
    Tab inserts a tab; with lines selected Tab and Shift+Tab indent and
    unindent them. Enter keeps the indentation of the line above.

FILES
    Saving writes a new copy and replaces the old file only when it is
    complete, keeping its permissions. A file that does not exist is created
    when you save.
