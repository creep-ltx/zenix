SHA256SUM(1)	Zenix manual

NAME
    sha256sum - print SHA-256 checksums

SYNOPSIS
    sha256sum [file...]

DESCRIPTION
    Prints the SHA-256 checksum of each file (standard input without
    arguments), in the same format as the GNU program: 64 hex digits, two
    spaces, the name. The same function hashes passwords (see passwd(1)).

NOTES
    Reads a file 4 KB at a time, so any size of file is summed in a few KB
    of memory. The output equals the host's sha256sum on the files that
    were compared. An access the user is not allowed is reported as
    "permission denied"; a read error is reported and gives status 1.

EXIT STATUS
    0, 1 if a file cannot be read.

SEE ALSO
    md5sum(1), base64(1)
