UPTIME(1)			Zenix manual

NAME
    uptime - how long the system has been running

SYNOPSIS
    uptime

DESCRIPTION
    Prints "up h:mm:ss", the whole seconds since the kernel started (the
    kernel counts them with its 100 Hz tick; the count goes on past 497
    days, where the 32-bit tick count wraps, and wraps only after 136
    years). There is no load average.

SEE ALSO
    date(1)
