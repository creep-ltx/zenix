MKFS.ZENIXFS(1)			Zenix manual

NAME
    mkfs.zenixfs - make a ZenixFS filesystem

SYNOPSIS
    mkfs.zenixfs [-b 10|11|12] [-l label] [-c latin1|utf8] device

DESCRIPTION
    Writes an empty ZenixFS filesystem (the format is in
    docs/zenixfs-format.md) on a device: a partition such as ide0p2, made
    with "fdisk add ... zenixfs". The old contents are lost. The device must
    not be mounted. The superblock gets a volume id (a uuid from the
    clocks): the filesystem server finds its volume by place and id after
    a restart.

    -b n      block size 1 << n bytes: 10 = 1 KB, 11 = 2 KB, 12 = 4 KB.
              Default: 1 KB under 16 MB, 2 KB under 256 MB, else 4 KB.
    -l label  volume label (31 characters).
    -c cs     which encoding the names on the volume use, latin1 (default)
              or utf8. A hint for programs; ZenixFS stores names as bytes.

EXAMPLES
    fdisk add ide0 data rest zenixfs
    mkfs.zenixfs ide0p2
    mount ide0p2 /mnt

EXIT STATUS
    0, 1 on an error (cannot open the device, too small), 2 usage. The
    usage line goes to the error stream.

NOTES
    The device must be at least a few hundred blocks. Formatting a whole disk
    (ide0) instead of a partition prints a warning.

SEE ALSO
