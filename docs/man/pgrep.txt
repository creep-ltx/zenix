PGREP(1)		Zenix manual

NAME
    pgrep - find processes by name

SYNOPSIS
    pgrep [-lx] name   /   pkill [-SIGNAL] [-x] name

DESCRIPTION
    pgrep prints the ids of processes whose program name contains name (-x:
    is exactly name; -l: also the name). pkill sends them SIGTERM (or
    the SIGNAL named, as kill(1)). Neither matches
    itself or the shell that started it. Exit status 0 if any process
    matched.

EXIT STATUS
    0 if a process matched, 1 if none did, 2 for a wrong option.


NOTES
    It looks through the whole process table (32 entries).
SEE ALSO
    ps(1), kill(1)
