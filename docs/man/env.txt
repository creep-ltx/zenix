ENV(1)			Zenix manual

NAME
    env - show the environment or run a command with changes to it

SYNOPSIS
    env [name=value...] [command [argument...]]

DESCRIPTION
    Without a command, prints the environment, one NAME=value per line (after
    applying any name=value arguments). With a command, sets the given
    variables and runs the command, passing the changed environment to it,
    and returns the command's exit status.

    A command without a slash is looked for in /bin only (not in $PATH).

EXAMPLES
    env
    env HOME=/tmp ls -a

EXIT STATUS
    The command's status, or 127 if it cannot be run.

SEE ALSO
    printenv(1), sh(1) (export, set)
