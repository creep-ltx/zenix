REALPATH(1)		Zenix manual

NAME
    realpath - print the real absolute name

SYNOPSIS
    realpath [-e] path...

DESCRIPTION
    Prints each path made absolute, with . and .. removed and symbolic links
    followed, at most 40 of them in one path, as the kernel follows them.
    With -e the path must exist.

NOTES
    A symbolic link whose target is 159 bytes or longer cannot be resolved
    (the longest path Zenix takes is 159 bytes): "cannot resolve", never a
    prefix of the target. More than 40 links in one path (a loop), a path
    over 319 bytes or a result over 159 cannot be resolved either (never
    cut). The resolver is libz's zrealpath, which wasabid(8) uses too.

EXIT STATUS
    0, 1 if a path cannot be resolved (or with -e does not exist).

SEE ALSO
    pwd(1), readlink(1)
