REALPATH(1)		Zenix manual

NAME
    realpath - print the real absolute name

SYNOPSIS
    realpath [-e] path...

DESCRIPTION
    Prints each path made absolute, with . and .. removed and symbolic links
    followed, at most 40 of them in one path, as the kernel follows them.
    With -e the path must exist.

NOTES
    More than 40 links in one path (a loop), a path over 511 bytes or a
    result over 255 (the longest path Zenix takes) cannot be resolved:
    "cannot resolve", never cut. The resolver is libz's zrealpath, which
    wasabid(8) uses too.

EXIT STATUS
    0, 1 if a path cannot be resolved (or with -e does not exist). With -e
    a missing path reads "realpath: PATH: no such file or directory".

SEE ALSO
    pwd(1), readlink(1)
