MKDIR(1)			Zenix manual

NAME
    mkdir - make directories

SYNOPSIS
    mkdir [-pv] directory...

OPTIONS
    -p    make missing parent directories as well, and do not complain
          if the directory already exists
    -v    print a line for each directory created

EXAMPLES
    mkdir work
    mkdir -p a/b/c

EXIT STATUS
    0, 1 if a directory exists or cannot be made, 2 usage error.

NOTES
    An access the user is not allowed is reported as "permission denied".
    An existing name says "exists"; any other failure gives its reason
    ("permission denied", "no such file or directory" for a missing parent
    ...).

SEE ALSO
    rmdir(1), rm(1)
