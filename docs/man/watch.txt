WATCH(1)		Zenix manual

NAME
    watch - run a command repeatedly

SYNOPSIS
    watch [-n seconds] command [argument...]

DESCRIPTION
    Clears the screen, runs the command through sh -c, waits and repeats
    (every 2 seconds unless -n). Ctrl+C ends it.

EXIT STATUS
    Only ends with Ctrl+C or when sh cannot be started (1).


NOTES
    The command runs in watch's process group, the shell's job: Ctrl+C
    ends both.
    The command may be any length: nothing of it is cut.
SEE ALSO
    sleep(1)
