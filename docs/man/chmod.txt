CHMOD(1)			Zenix manual

NAME
    chmod - change permission bits

SYNOPSIS
    chmod mode file...

DESCRIPTION
    Sets the permission bits of each file. The mode is either an octal
    number (755, 0644) or a symbolic list separated by commas:

        [ugoa]...  +|-|=  [rwxX]...

    u user (owner), g group, o others, a all (the default); + adds, - removes,
    = sets exactly; r read, w write, x execute, X execute only for
    directories or files that are already executable by someone.

    The special bits (setuid, setgid, sticky) can only be set with an octal
    mode. Set-user-id makes a program run as its owner (su, passwd); sticky on
    a directory (/tmp) lets only a file's owner remove it.

EXAMPLES
    chmod 755 script
    chmod u+x,go-w file
    chmod a=r notes

NOTES
    Only the owner of a file and root may change its mode. The bits are
    enforced by the filesystem server (see architecture.md, users); root
    passes every check except executing a file without any x bit.

EXIT STATUS
    0, 1 if a file is not found or cannot be changed, 2 invalid mode.

SEE ALSO
    ls(1), stat(1)
