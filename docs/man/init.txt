INIT(8)			Zenix manual

NAME
    init - the first program

SYNOPSIS
    started by boot; not run by hand

DESCRIPTION
    /bin/init is process 1. It prints /etc/motd, starts /bin/login with the
    terminal as its input and output, makes it the foreground program, and
    waits. When the session ends, init says so, tells the kernel that
    nobody is logged in and starts login again, so the console is never
    left without one.

SEE ALSO
    boot(8), login(1)
