INIT(8)			Zenix manual

NAME
    init - the first program

SYNOPSIS
    started by boot; not run by hand

DESCRIPTION
    /bin/init is process 1. It prints /etc/motd, runs "mount -a" if there is
    an /etc/fstab (so the filesystems listed there are mounted before anyone
    can log in), starts /bin/login with the
    terminal as its input and output, makes it the foreground program, and
    waits. When the session ends, init says so, tells the kernel that
    nobody is logged in (SYS_session with uid -1: from then on Amiga+Return
    opens no shell until someone logs in) and starts login again, so the
    console is never left without one.

SEE ALSO
    boot(8), login(1), mount(8)
