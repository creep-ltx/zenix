INIT(8)			Zenix manual

NAME
    init - the first program

SYNOPSIS
    started by boot; not run by hand

DESCRIPTION
    /bin/init is process 1. It prints /etc/motd, starts /bin/sh with the
    terminal as its input and output, makes it the foreground program, and
    waits. When the shell ends, init says so and starts a new one, so the
    console is never left without a shell.

SEE ALSO
    boot(8), sh(1)
