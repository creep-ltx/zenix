# Zenix

A small, fast, POSIX-like operating system for real Amigas with a 68020 or better and **no MMU needed**.
It runs on the Amiga itself: no Raspberry Pi, no emulation layer, no AmigaOS underneath.

Status: restarted 2026-10-22 from `Archive/zenix-old` (the 68030+MMU version). The MMU, address-space and
FPU code is parked in `old-mmu/` and is not built. Nothing here has been built or run since the restart.
