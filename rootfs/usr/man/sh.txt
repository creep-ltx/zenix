SH(1)			Zenix manual

NAME
    sh - the Zenix shell

SYNOPSIS
    sh [file [argument...]]      run a script
    sh -c 'commands' [name [argument...]]
    sh                           an interactive shell

LINE EDITING
    Left, Right   move             Ctrl+Left, Ctrl+Right (Home, End)   start / end of the line
    Ctrl+A, Ctrl+E start / end     Ctrl+B, Ctrl+F    back / forward a character
    Alt+Left/Right a word back / on
    Backspace, Del, Ctrl+D delete (Ctrl+D on an empty line ends the shell)
    Ctrl+K cut to the end   Ctrl+U cut to the start   Ctrl+W cut the word before   Ctrl+T swap two characters
    Up, Down  (Ctrl+P, Ctrl+N)  earlier and later commands: the history is kept in ~/.sh_history
    Tab       complete a command, a file name or a $variable; twice lists the choices
    Ctrl+L    clear the screen          Ctrl+C   cancel the line

LANGUAGE
    Commands:   name arg...           a program found in $PATH, a builtin, a function or an alias
    Variables:  NAME=value            $NAME ${NAME} ${NAME:-default} ${NAME:=default} ${NAME:+other} ${#NAME}
                $? status of the last command   $$ shell pid   $# $1..$9 $@ $* the arguments   $! last background pid
    Quoting:    'literal'  "with $expansion"  \x escapes one character
    Expansion:  $(command) or `command` the command's output;  $((1+2*3)) arithmetic;  ~ the home directory
    Wildcards:  * any text  ? one character  [abc] [a-z] [!a]  (names starting with . need a literal .)
    Pipes and lists:  a | b   a && b   a || b   a ; b   a &   ! a   ( a; b )   { a; b; }
    Redirection:  < file   > file   >> file   2> file   2>&1   &> file   <<WORD (a here-document; <<-WORD strips tabs)
    Conditions:   if list; then list; elif list; then list; else list; fi
    Loops:        while list; do list; done      until list; do list; done      for x in words; do list; done
    Functions:    name() { commands; }      return [n]   break [n]   continue [n]
    Scripts:      first line  # comments;  sh file   or   . file
    A command that is a variable assignment only (A=1) sets a shell variable; A=1 command passes it to that command only.

BUILTINS
    cd [dir|-]  exit [n]  export NAME[=value]  unset NAME  set [-- args]  alias [name=value]  unalias name
    history [-c]  source file (or . file)  read [-p prompt] name...  shift [n]  return  break  continue
    jobs  wait [pid|%n]  kill pid|%n  type name  test expr (or [ expr ])  true false :  echo [-ne]  pwd  eval  local  help
    test: -e -f -d -r -w -x -s -z -n -L, = != -eq -ne -lt -le -gt -ge, ! -a -o ( )

VARIABLES THE SHELL USES
    PATH (default /bin)  HOME  USER  HOSTNAME  PS1 (prompt: \w directory, \W its name, \u user, \h host, \$ # or $, \n)
    PS2 (the continuation prompt)  IFS  PWD  OLDPWD  TERM  LINES  COLUMNS
    Start-up files: /etc/profile and ~/.shrc (read by an interactive shell).

JOBS
    command &   runs in the background; jobs lists them; wait waits; kill %1 stops one.
    Ctrl+C stops the program in the foreground (and a loop the shell itself is running).
